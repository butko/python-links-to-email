# Link Monitor — мониторинг новых ссылок с уведомлением по email

Скрипт на Python, который периодически обходит заданные источники (обычные веб-страницы и сообщества ВКонтакте), находит новые ссылки, сохраняет их в локальный файл и отправляет каждую новую ссылку отдельным письмом.

---

## Возможности

- Обход нескольких источников: обычные сайты и сообщества ВКонтакте
- Фильтрация ссылок по регулярным выражениям (для каждого источника свои фильтры)
- Работа с ВКонтакте через официальный VK API
- Извлечение заголовка страницы для темы письма (для обычных сайтов)
- Извлечение текста поста, текстов репостов и описания вложений (для VK)
- Встраивание фотографий из постов ВК прямо в тело письма с ограничением по размеру
- Хранение истории обработанных ссылок в локальном файле
- Гибкая настройка через INI-конфиг

## Быстрый старт

1. Установите зависимости.
2. Заполните `config.txt` (см. раздел «Конфигурация»).
3. Запустите скрипт:

       python python-links-to-email.py

При первом запуске создастся `links.txt`, и все найденные ссылки будут отправлены письмами. При последующих запусках — только новые.

## Конфигурация

Файл `config.txt` состоит из секций. Секции `[smtp]` и `[vk]` — служебные, все остальные — источники.

### Секция `[smtp]`

| Параметр | Обязательный | Описание |
|----------|:------------:|----------|
| `EMAIL` | да | Адрес получателя уведомлений |
| `SMTP_SERVER` | да | Адрес SMTP-сервера (например, `smtp.example.com`) |
| `SMTP_PORT` | да | Порт (обычно `587` для STARTTLS) |
| `SMTP_USER` | да | Логин отправителя (полный email) |
| `SMTP_PASSWORD` | да | Пароль приложения (не обычный пароль!) |
| `ATTACH_PHOTOS` | нет | `yes`/`no` — прикреплять ли фото из постов ВК |
| `PHOTO_TARGET_WIDTH` | нет | Желаемая ширина фото в пикселях (по умолчанию 600) |
| `PHOTO_MAX_COUNT` | нет | Максимум фото в одном письме (по умолчанию 10) |
| `PHOTO_MAX_KB` | нет | Максимум размера одной картинки в КБ (по умолчанию 500) |

### Секция `[vk]`

| Параметр | Обязательный | Описание |
|----------|:------------:|----------|
| `api_token` | да (если есть VK-источники) | Токен доступа VK API |
| `api_version` | нет | Версия API (по умолчанию `5.199`) |

### Секции источников `[source_*]`

Имя секции произвольное, кроме `smtp` и `vk`.

| Параметр | Обязательный | Описание |
|----------|:------------:|----------|
| `url` | да | Адрес страницы или сообщества |
| `filters` | нет | Список regex-паттернов через запятую. Ссылка остаётся, если соответствует хотя бы одному. Если не задан — берутся все ссылки |
| `type` | нет | `vk` или `web`. Если не задан — определяется автоматически по домену |
| `api_token` | нет | Только для VK. Переопределяет общий токен из `[vk]` |
| `api_version` | нет | Только для VK. Переопределяет версию из `[vk]` |
| `count` | нет | Только для VK. Сколько последних постов загружать (максимум 100) |

## Как получить токен VK API

Токен нужен только если вы используете источники ВКонтакте (домены `vk.com`, `vk.ru`, `vkvideo.ru`).

### Вариант 1 — токен сообщества (для одного сообщества)

1. Откройте своё сообщество.
2. Перейдите в «Управление» → «Настройки» → «Работа с API».
3. Нажмите «Создать ключ».
4. Выберите право `wall` (доступ к стене).
5. Скопируйте полученный токен в `api_token` секции `[vk]` (или конкретного источника).

Такой токен работает **только для этого сообщества**. Для нескольких сообществ используйте вариант 2.

### Вариант 2 — пользовательский токен (для нескольких сообществ)

1. Зарегистрируйтесь на платформе для разработчиков VK.
2. Создайте Standalone-приложение.
3. Получите токен через Implicit Flow с правами `wall` и `offline`.
4. Укажите этот токен в `[vk]` — он подойдёт для всех VK-источников.

**Никогда не публикуйте токен.** Ограничьте права на файл конфига:

    chmod 600 config.txt

## Как получить пароль приложения для SMTP

Большинство почтовых провайдеров не принимают обычный пароль для сторонних приложений — нужен **пароль приложения**.

- **Яндекс.Почта:** настройки аккаунта → «Безопасность» → «Пароли приложений». Создайте пароль для «Почты».
- **Gmail:** включите двухфакторную аутентификацию, затем создайте пароль приложения для «Почты».
- **Mail.ru:** аналогично — в настройках безопасности.
- **Другие провайдеры:** ищите раздел «Пароли приложений» или «Доступ для сторонних приложений».

Полученный пароль укажите в `SMTP_PASSWORD`.

## Пример конфига

    [smtp]
    EMAIL = recipient@example.com
    SMTP_SERVER = smtp.example.com
    SMTP_PORT = 587
    SMTP_USER = sender@example.com
    SMTP_PASSWORD = your_app_password
    ATTACH_PHOTOS = yes
    PHOTO_TARGET_WIDTH = 600
    PHOTO_MAX_COUNT = 10
    PHOTO_MAX_KB = 500

    [vk]
    api_token = your_vk_access_token
    api_version = 5.199

    [source_news]
    url = https://example.com/news
    filters = /news/

    [source_vk_community]
    url = https://vk.ru/example_community
    filters = wall-
    count = 100

## Как работают фильтры

`filters` — это список регулярных выражений, разделённых запятыми. Ссылка проходит фильтр, если соответствует **хотя бы одному** паттерну.

Примеры:

- `filters = /news/` — ссылки, содержащие `/news/`
- `filters = clip-, video-` — ссылки, содержащие `clip-` **или** `video-`
- `filters = \d{4}/\d{2}` — ссылки вида `/2026/10`
- `filters = (?i)news` — регистронезависимый поиск слова `news`

Если `filters` не задан — с источника принимаются все ссылки.

## Как выбирается тема письма

- **Обычные сайты:** заголовок страницы из тега `<title>`.
- **ВКонтакте:** текст поста (обрезанный до 200 символов). Если текста нет — берётся текст репоста. Если и его нет — перечисляются вложения (`Фото: 3, Видео: 1`). Если совсем ничего — `Пост без текста`.
- **Метка источника** добавляется в начало темы: `Новая ссылка (example.com): ...` или `Новая ссылка (vk.ru/club123456): ...`.

---

## Как работает вложение фото из ВКонтакте

- Из каждого поста извлекается список фотографий.
- Для каждой выбирается размер, ближайший к `PHOTO_TARGET_WIDTH`, но не больше `PHOTO_TARGET_WIDTH * 1.5`.
- Скачивается не больше `PHOTO_MAX_COUNT` фото, каждое не больше `PHOTO_MAX_KB` КБ.
- Картинки встраиваются прямо в тело письма через `Content-ID`.
- Файлы **не сохраняются на диск** — всё держится в оперативной памяти и освобождается после отправки письма.

## Ограничение по количеству постов ВКонтакте

Параметр `count` в секции VK-источника задаёт, сколько последних постов загружать. VK API возвращает максимум 100 постов за один запрос — если указать больше, всё равно вернётся только 100.

Для регулярного мониторинга (раз в час, раз в день) достаточно `count = 20–50`. Увеличение `count` полезно только при первом запуске, чтобы захватить историю.

## Устранение неполадок

### `Connection refused` при отправке письма

- Неверный адрес или порт SMTP. Уточните у провайдера: `smtp.example.com:587`.
- Локальный SMTP не запущен (если вы указали `localhost`). Используйте внешний SMTP.

### `534 5.7.9 Application-specific password required`

- Провайдер требует пароль приложения, а не обычный пароль. См. раздел выше.

### `535 5.7.8 Error: authentication failed`

- Неверный логин или пароль.
- Для Яндекса: включён ли доступ по SMTP в настройках почты?
- Для Gmail: включена ли двухфакторная аутентификация?

### `User authorization failed: invalid access_token`

- Токен недействителен или истёк.
- Токен сообщества подходит только для своего сообщества.
- Проверьте токен в браузере:

      https://api.vk.com/method/wall.get?domain=example_community&count=1&access_token=ВАШ_ТОКЕН&v=5.199

### `%` must be followed by `%` or `(`

- В URL есть символы вида `%2C`. Скрипт отключает интерполяцию, поэтому этой ошибки быть не должно. Если она возникла — обновите скрипт до актуальной версии.

### Сайт блокирует запросы

- Скрипт отправляет `User-Agent`. Если сайт всё равно блокирует — попробуйте заменить `User-Agent` в функциях `fetch_links_from_page` и `get_page_title`.
